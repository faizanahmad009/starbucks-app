****Starbucks Drink Category Predictor****
Predicts the category of a Starbucks drink (Coffee, Classic Espresso, Tazo Tea, etc.) from its nutrition values using a Random Forest model.

Live app: https://starbucks-predictor.streamlit.app/

**Note:** This is a learning project trained on 242 drinks (about 80% test accuracy). It is not a professional tool.

Dataset: Starbucks drinks by henryshan on Kaggle.
